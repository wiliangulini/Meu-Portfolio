# /melhorar-ui-ux

Atue como engenheiro front-end sênior com foco em UI/UX.

Tarefa:
[DESCREVA A MELHORIA VISUAL]

Antes de alterar:

1. Identifique framework e padrão visual atual.
2. Leia componentes, templates, estilos e rotas envolvidos.
3. Preserve responsividade.
4. Preserve comportamento funcional.
5. Não reescreva a tela inteira sem necessidade.
6. Não introduza biblioteca visual sem aprovação.

Avalie:

- hierarquia visual;
- responsividade;
- estados de loading/erro/vazio;
- acessibilidade básica;
- consistência visual;
- legibilidade;
- impacto em fluxo do usuário.

Implemente incrementalmente e valide com build/lint quando disponível.

Ao final, entregue:

- o que mudou;
- arquivos alterados;
- impacto visual;
- validações;
- riscos.
