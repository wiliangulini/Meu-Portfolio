# /auditar-arquitetura

Atue como arquiteto de software sênior.

Não altere arquivos.

Objetivo:
Auditar a arquitetura da área abaixo.

Área/módulo:
[DESCREVA O MÓDULO]

Avalie:

- separação de responsabilidades;
- acoplamento;
- duplicação;
- testabilidade;
- fluxo de dados;
- autenticação/autorização, se aplicável;
- integração com API/banco;
- pontos de falha;
- aderência aos padrões do projeto;
- riscos de manutenção;
- oportunidades de simplificação.

Obrigatório:

- basear conclusões em arquivos reais;
- não inventar estrutura;
- citar arquivos analisados;
- separar problemas reais de preferências;
- classificar achados por severidade;
- propor plano incremental de melhoria.

Entregue relatório com:

- visão geral;
- arquitetura atual;
- principais riscos;
- recomendações priorizadas;
- plano de ação por etapas.
